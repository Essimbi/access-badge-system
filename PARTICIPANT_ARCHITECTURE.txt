SERVICES UTILISÉS
================================================================================

1. ApiService
   Méthodes utilisées:
   ├─ getEvents(options?: any): Observable<Event[]>
   │  └─ Récupère la liste des événements
   ├─ downloadBadgePDF(badgeId: number): Observable<Blob>
   │  └─ Télécharge un badge en PDF
   ├─ updateProfile(data: any): Observable<any>
   │  └─ Met à jour le profil utilisateur
   └─ getProfile(): Observable<any>
      └─ Récupère le profil utilisateur

2. AuthService
   Propriétés utilisées:
   ├─ currentUser$: Observable<User | null>
   │  └─ Observable de l'utilisateur actuel
   └─ Méthodes utilisées:
      ├─ hasAnyRole(roles: string[]): boolean
      │  └─ Vérifie si l'utilisateur a l'un des rôles
      └─ logout(): void
         └─ Déconnecte l'utilisateur

3. NotificationService
   Méthodes utilisées:
   ├─ success(message: string): void
   │  └─ Affiche une notification de succès
   ├─ error(message: string): void
   │  └─ Affiche une notification d'erreur
   └─ info(message: string): void
      └─ Affiche une notification d'information

INTERFACES DE DONNÉES
================================================================================

ParticipantStats:
interface ParticipantStats {
  totalEvents: number;        // Nombre total d'événements
  totalHours: number;         // Heures totales de participation
  badgesCollected: number;    // Badges collectés
  upcomingEvents: number;     // Événements à venir
}

Event:
interface Event {
  id: number;                 // ID de l'événement
  title: string;              // Titre
  description?: string;       // Description
  date: Date;                 // Date
  location: string;           // Lieu
  status: 'upcoming' | 'ongoing' | 'completed';  // Statut
  type?: string;              // Type d'événement
  organization?: string;      // Organisation
  badgeCategory?: string;     // Catégorie du badge
  badgeId?: number;           // ID du badge
  enrolled?: boolean;         // Inscription
  participants?: number;      // Nombre de participants
  maxParticipants?: number;   // Capacité maximale
}
