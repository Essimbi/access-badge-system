================================================================================
GUIDE DE LECTURE
================================================================================

POUR COMMENCER:
1. Lire README_CONTROLLER.txt ou README_PARTICIPANT.txt
2. Lire QUICK_START.txt ou PARTICIPANT_QUICK_START.txt
3. Démarrer l'application

POUR UTILISER L'APPLICATION:
1. Lire CONTROLLER_USAGE_GUIDE.txt ou PARTICIPANT_USAGE_GUIDE.txt
2. Consulter CONTROLLER_FEATURES.txt ou PARTICIPANT_FEATURES.txt
3. Utiliser l'application

POUR COMPRENDRE L'ARCHITECTURE:
1. Lire CONTROLLER_ARCHITECTURE.txt ou PARTICIPANT_ARCHITECTURE.txt
2. Consulter FILES_MANIFEST.txt (pour le contrôleur)
3. Examiner le code source

POUR TESTER L'APPLICATION:
1. Lire TESTING_GUIDE.txt (pour le contrôleur)
2. Exécuter les scénarios de test
3. Documenter les résultats

POUR DÉPLOYER L'APPLICATION:
1. Lire IMPLEMENTATION_COMPLETE.txt (pour le contrôleur)
2. Consulter CHANGES_SUMMARY.txt (pour le contrôleur)
3. Suivre la checklist de déploiement
