PARTICIPANT - GUIDE DE DÉMARRAGE RAPIDE
================================================================================

INSTALLATION
================================================================================

1. Prérequis:
   - Node.js 18+ installé
   - npm ou yarn installé
   - Angular CLI 21+ installé

2. Installation des dépendances:
   npm install

3. Démarrage du serveur de développement:
   npm start
   ou
   ng serve

4. Accès à l'application:
   http://localhost:4200

CONNEXION
================================================================================

1. Allez à la page de connexion:
   http://localhost:4200/auth/login

2. Entrez les identifiants:
   Email: participant@example.com
   Mot de passe: password123

3. Cliquez sur "Se connecter"

4. Vous serez redirigé vers le tableau de bord participant

FONCTIONNALITÉS PRINCIPALES
================================================================================

1. MON ESPACE
   - Accès: /dashboard/participant
   - Affiche vos statistiques personnelles
   - Liste vos événements à venir et passés
   - Gère vos badges

2. PARCOURIR LES ÉVÉNEMENTS
   - Accès: /dashboard/participant/browse-events
   - Découvrez les événements disponibles
   - Filtrez par type, statut, organisation
   - Inscrivez-vous aux événements

3. MON PROFIL
   - Accès: /dashboard/participant/profile
   - Gérez vos informations personnelles
   - Changez votre mot de passe
   - Configurez vos préférences
   - Téléchargez vos données

COMMANDES UTILES

DÉPANNAGE
================================================================================

Problème: La page ne charge pas
Solution:
1. Vérifiez que le serveur est en cours d'exécution
2. Vérifiez l'URL (http://localhost:4200)
3. Vérifiez la console pour les erreurs
4. Rafraîchissez la page (Ctrl+R ou Cmd+R)

Problème: Les données ne s'affichent pas
Solution:
1. Vérifiez que vous êtes connecté
2. Vérifiez que le rôle est "participant"
3. Vérifiez les logs de la console
4. Vérifiez que l'API est accessible

Problème: Les filtres ne fonctionnent pas
Solution:
1. Vérifiez que les données sont chargées
2. Essayez de réinitialiser les filtres
3. Rafraîchissez la page
4. Vérifiez la console pour les erreurs

Problème: L'inscription ne fonctionne pas
Solution:
1. Vérifiez que l'événement a des places disponibles
2. Vérifiez que vous n'êtes pas déjà inscrit
3. Vérifiez les logs de la console
4. Essayez de rafraîchir la page
